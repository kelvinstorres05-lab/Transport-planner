ATUALIZAÇÃO - JANELAS DE RECEBIMENTO POR DATA

Nova aba: Janelas de Recebimento

Para cada data do Planned/Firmed Receipts, o site cria automaticamente uma janela:
- Data da entrega
- Semana ISO (ex.: 25/08/2026 = S35)
- Quantidade de Part Numbers
- Total de peças
- Total de pallets
- Quantidade de carretas
- Taxa de ocupação
- Status 85% a 100%

Ao expandir a janela, o site mostra:
- Part Number
- Descrição
- Planned Receipts
- Firmed Receipts
- Quantidade considerada na entrega
- Itens por pallet
- Pallets
- Status de embalagem

Modos disponíveis:
- Usar modo do Planejamento
- Priorizar Firmed
- Somente Planned
- Somar Planned + Firmed
- Maior entre Planned/Firmed

Para atualizar o GitHub Pages:
substitua index.html, app.js e styles.css no repositório e faça Commit changes.
