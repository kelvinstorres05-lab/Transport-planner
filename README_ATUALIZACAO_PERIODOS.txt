ATUALIZAÇÃO - PERÍODOS DE PLANNED / FIRMED RECEIPTS

- Detecta automaticamente o formato SAP com datas nas colunas e o campo Texto contendo Planned Receipts / Firmed Receipts.
- Permite Data Inicial e Data Final separadamente para Planned Receipts.
- Permite Data Inicial e Data Final separadamente para Firmed Receipts.
- Soma todas as quantidades dentro do intervalo escolhido por material.
- Identifica automaticamente a semana ISO. Ex.: 24/08/2026 a 28/08/2026 = S35.
- Planned e Firmed podem usar o mesmo intervalo ou intervalos diferentes.
- Após consolidar o período, recalcula pallets, carretas, ocupação, saving e CO2.
