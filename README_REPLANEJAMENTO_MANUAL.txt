ATUALIZAÇÃO - REPLANEJAMENTO MANUAL ENTRE JANELAS

Nova função na aba Janelas de Recebimento:

1. DRAG AND DROP
- Cada Part Number pode ser arrastado de uma janela/data para outra.
- Também existe o campo "Mover para" como alternativa ao arrastar.
- A quantidade do item e os dados de embalagem são preservados.

2. REPROCESSAR CENÁRIO
Após fazer os movimentos, clique em "Reprocessar cenário".
O site recalcula a distribuição atual:
- pallets por janela
- carretas por janela
- ocupação
- total de veículos
- saving
- km
- CO2
- Dashboard e impactos

3. RESETAR ORIGINAL
"Resetar original" devolve todos os itens exatamente às datas em que estavam quando o último arquivo de Planejamento foi importado.

4. COMPORTAMENTO
- Enquanto houver movimentos ainda não reprocessados, o site sinaliza o cenário como pendente.
- A distribuição original continua preservada internamente.
- Uma nova importação de Planejamento passa a ser o novo "original".
