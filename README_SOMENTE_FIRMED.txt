ATUALIZAÇÃO — SOMENTE FIRMED

Foi criada uma nova opção independente:
SOMENTE FIRMED

Diferença:
- Somente Firmed: considera APENAS registros com Firmed > 0.
  Um Part Number que tenha Planned > 0 e Firmed = 0 NÃO entra no planejamento.
- Priorizar Firmed: continua com o comportamento anterior.
  Usa Firmed quando existe; se não existir, pode utilizar Planned.
- Somente Planned: considera apenas Planned.
- Planned + Firmed: soma os dois.
- Maior entre Planned/Firmed: utiliza o maior valor.

Uso:
1. Abra Janelas de Recebimento.
2. No seletor, escolha “Somente Firmed”.
3. As janelas serão recalculadas mostrando somente os PNs firmados.
4. Faça os remanejamentos desejados.
5. Clique em “Reprocessar cenário”.

A versão foi construída sobre o pacote REPROCESSAMENTO CORRIGIDO.
